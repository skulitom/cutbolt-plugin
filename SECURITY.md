# Security

Please report a security problem privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Don't open a public issue for it.

This repository holds only the Claude Code plugin (a manifest, skills and their eval cases). Problems in Cutbolt
itself can be reported the same way on [skulitom/Cutbolt](https://github.com/skulitom/Cutbolt/security).
